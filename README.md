Regressão Linear por Mínimos Quadrados

Este projeto apresenta um script em Python para realização de regressão linear de dados experimentais pelo método dos mínimos quadrados.

O programa permite inserir os pontos experimentais, calcula os coeficientes da reta de ajuste linear e apresenta graficamente os pontos medidos juntamente com a reta de regressão.

A reta obtida é representada na forma:


y = ax + b

onde (a) corresponde ao coeficiente angular e (b) ao coeficiente linear.

O script foi desenvolvido com finalidade educacional e científica, podendo ser utilizado no tratamento e análise de dados experimentais.
